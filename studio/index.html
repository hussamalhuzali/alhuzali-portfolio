First-time setup
  1. In GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Create a token named Portfolio Studio with a short expiration.
  3. Select only alhuzali-portfolio.
  4. Grant repository Contents: Read and write and Actions: Read-only. Leave account permissions empty.
  5. Paste the token above. Never send it in chat.
